# LinkedIn post draft

I’m building **Synth ID and AI Media Provenance Cleaner**, a Windows-focused fork of the MIT-licensed `watermarks-remover` project.

The project can inspect and clean supported image and video file metadata. For still photos, I’m also setting up an optional CUDA-enabled CtrlRegen workflow that regenerates image pixels. Regeneration is best-effort and can change fine details; results need visual review. Video pixel-watermark removal is not supported yet.

I’m documenting the setup, limitations, and licensing boundaries as I develop it. The core fork keeps its upstream MIT notice, while optional third-party model backends have their own terms and are not all redistributable.

Project: https://github.com/agent-47-cyber/syth-id-and-watermarks-remover
